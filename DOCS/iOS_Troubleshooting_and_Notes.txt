####### FCM

Need Developer account - 99/yr
https://icloud.developer.apple.com/dashboard/notifications

Get an APNs Auth Key .p8
Go to Apple Developer → Certificates, Identifiers & Profiles.
In the sidebar, open Keys.
Click + to create a new key.
Name it e.g. Firebase APNs Key and enable Apple Push Notifications service APNs.
Create, then download the .p8 file only downloadable once.
Save these 3 values:
Key ID shown in Apple portal
Team ID from Apple account membership page
.p8 file itself
Then upload in Firebase:
Firebase Console → Project Settings → Cloud Messaging → iOS app section → upload .p8, enter Key ID and Team ID.
Store the .p8 securely password manager/secret vault, and don’t commit it to git.
